# Project Documentation

## Project Name
Olist E-Commerce Intelligence Dashboard

## Objective
The objective of this project was to transform raw Brazilian e-commerce data into an interactive Business Intelligence solution that provides insights into sales performance, customer behaviour, product performance, and operations and delivery efficiency.

## Business Questions
The analysis was designed to answer the following questions:

* How is revenue performing over time?
* Which product categories generate the most revenue?
* Which categories have the highest order volume?
* How many customers make repeat purchases?
* How much revenue is generated by repeat customers?
* How efficient is the delivery process?
* What percentage of orders are cancelled or unavailable?
* Which areas present opportunities for business improvement?

## Data Preparation
The dataset was prepared using Power Query. The data preparation process included:

* Reviewing data types
* Identifying missing values
* Investigating duplicate records
* Preparing product category information
* Creating calculated fields for analysis
* Creating relationships between tables
* Creating a dedicated Calendar table for time-based analysis

## Data Modelling
The Power BI model connects key business entities including:

* Customers
* Orders
* Order Items
* Products
* Payments
* Sellers
* Reviews
* Calendar

The model supports analysis across sales, customers, products, and delivery operations.

## Analysis Areas

### Sales Analysis
Analysed revenue trends, monthly revenue growth, product category revenue, order volume, and quantity sold.

### Customer Analysis
Analysed one-time customers, repeat customers, repeat customer revenue, orders per customer, and revenue per customer.

### Product Analysis
Compared product categories using revenue, order volume, quantity sold, and revenue contribution.

### Operations & Delivery Analysis
Analysed order status, delivery performance, average delivery days, on-time delivery, cancellations, unavailable orders, and delivery-day distribution.

## Key Findings
* Revenue is concentrated among a relatively small group of product categories.
* The majority of customers are one-time purchasers.
* Repeat customers represent a relatively small portion of the customer base, creating an opportunity for improved retention.
* High order volume does not always correspond to the highest revenue.
* Delivery performance is strong, with approximately 95% of deliveries completed on time.
* Cancelled and unavailable orders remain below 1%.
* A small number of unusually delayed orders may influence the overall average delivery time.
